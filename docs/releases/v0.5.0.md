## Что нового

- Новый главный экран: живая диаграмма диска, понятная разбивка занятого, свободного и освобождаемого macOS места, быстрые карточки инструментов.
- Плавная обратная связь кнопок и меню; адаптивные области сканирования; поддержка «Уменьшения движения» и остановка декоративных анимаций в неактивном окне.
- Завершение сканирования больше не перебрасывает в другой раздел, если пользователь уже ушёл с экрана сканирования.
- Единицы объёма, относительные даты и время теперь используют выбранный в приложении язык.
- Исправлен оставшийся объём результатов после очистки и подписи пустых результатов. Взаимоисключающие операции защищены от параллельного запуска.
- Включены предыдущие улучшения: расширенный поиск точных остатков приложений, отдельные ручные действия с памятью и DNS, проверка старых неактивных Codex runtimes, анимация Smart Shredder по реальным байтам с превью файла.
- Добавлен DMG с ярлыком «Программы»; ZIP остаётся альтернативой. Оба формата сопровождаются SHA-256.

## Установка

Скачайте **CleanMac.dmg**, откройте его и перетащите **CleanMac.app** в **Applications / Программы**. Можно также распаковать ZIP. Для проверки загрузки используйте соответствующий файл `.sha256`:

```sh
shasum -a 256 -c CleanMac.dmg.sha256
```

Требуются **macOS 14+** и **Apple Silicon (arm64)**. Версия приложения — **0.5.0 (6)**.

## Подпись и поведение

Эта сборка подписана **ad-hoc**, не имеет Developer ID и не нотарифицирована Apple. Gatekeeper может ограничивать запуск скачанной сборки. Защитные настройки macOS отключать не требуется для сборки из исходников.

Сканирование не удаляет файлы. Обычная очистка и дубликаты используют Корзину после подтверждения. Необратимое удаление приложений выбирается отдельно; Smart Shredder требует отдельного подтверждения и не обещает физическое стирание всех копий на SSD/APFS. Обслуживание памяти/DNS запускается только вручную с системной авторизацией.
