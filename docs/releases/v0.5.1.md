## Исправления

- Исправлено зависание при запуске с ранее сохранёнными настройками сканирования, а также вызванные им высокая загрузка CPU и рост памяти.
- Получение данных о диске перенесено в фон; повторные запросы объединяются и используют кэш, сохраняя отзывчивость интерфейса.
- Настройки и выбор областей сканирования сохраняются. Сбрасывать настройки или устанавливать приложение начисто не требуется.

**Версия: 0.5.1 (7).** Замените `CleanMac.app` в «Программах» приложением из DMG или ZIP. Для обоих архивов доступны SHA-256. Требуются macOS 14+ и Apple Silicon. Сборка подписана ad-hoc и не нотарифицирована Apple.

## Fixes

- Fixed a startup freeze with existing scan preferences, including the resulting high CPU usage and memory growth.
- Disk-capacity reads now run in the background; concurrent requests share cached results to keep the interface responsive.
- Existing settings and scan selections are preserved. No preference reset or clean installation is needed.

**Version: 0.5.1 (7).** Replace `CleanMac.app` in Applications using the DMG or ZIP. Both archives include SHA-256 checksums. Requires macOS 14+ and Apple Silicon. The build is ad-hoc signed and is not notarized by Apple.
