# CleanMac v0.5.2

## Русский

Исправлен запуск по значку: CleanMac мог работать в фоне, но не показывать главное окно. Приложение ошибочно считало обычный запуск фоновым, если macOS ещё не успела сделать его активным. Теперь режим определяется по событию запуска macOS, а обычный запуск явно показывает окно, в том числе при задержке создания окна SwiftUI.

Настройки и выбранные области сканирования сохраняются. Добавлены семь регрессионных проверок обычного запуска, запуска при входе, запуска службы и повторного открытия; они выполняются в CI.

**Версия: 0.5.2 (8).** Замените `CleanMac.app` в «Программах» приложением из DMG или ZIP. Оба архива сопровождаются SHA-256. Требуются macOS 14+ и Apple Silicon. Сборка подписана ad-hoc и не нотарифицирована Apple.

## English

Fixed launches where clicking the CleanMac icon started the process but left the main window hidden. The app previously mistook an ordinary launch for a background launch while macOS had not yet activated it. Launch mode now uses the macOS launch event, and normal launches explicitly show the window, including when SwiftUI creates it later.

Settings and scan selections are preserved. Seven regression checks cover ordinary, login-item, service and reopen events and run in CI.

**Version: 0.5.2 (8).** Replace `CleanMac.app` in Applications using the DMG or ZIP. Both archives include SHA-256 checksums. Requires macOS 14+ and Apple Silicon. The build is ad-hoc signed and is not notarized by Apple.
